# UI Vision: Search View

Search View is the Atlasphere visual component that allows the user to specify the actual `QuerySpec` they want to run in order to return a set of map markers (and corresponding URL, suitable for sharing) for display in the Map View.

The Search View should be able to be accessed easily but should not obscure the Map View when not in use.
One idea is for it to be a panel that slides down from the top of the screen, allowing the user to fill in values as well as view the current `QuerySpec` settings defining the current view.
